## Upload filename note

GitHub currently shows some uploaded filenames with a duplicated extension, such as `primary-classroom.jpg.jpg` and `school-building-front.jpg.jpeg`. The website references should match the exact uploaded filename, or the files should be renamed to the clean names in the main checklist before wiring them into the pages.
